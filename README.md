Hyperparameter Optimization & Statistical Analysis Workflow

This repository contains the code and methodology used to analyze and evaluate hyperparameter optimization performance. The workflow combines Python-based machine learning experiments with R-based statistical evaluation, including Analysis of Variance (ANOVA) and the Scott-Knott (SK) mean grouping test.

🛠️ Requirements & Dependencies

Python Environment:

Python 3.8+

Essential libraries: pandas, numpy, scikit-learn (or specific framework libraries used in your project)

R Environment:

R 4.0+

R packages: ScottKnott, agricolae (if needed for post-hoc analyses), readxl/tidyverse

📋 Execution Workflow

Follow the steps below to reproduce the complete experimental process and statistical analysis.

Step 1: Python Processing & Feature Screening (Part 1)

Open and run the initial cells of the provided Python notebook/script (.py or .ipynb).

Objective: Evaluate the model performance across initial parameter sets and identify the hyperparameters demonstrating the largest variance or impact on performance.

Select and isolate these high-impact hyperparameters to move forward into the combination phase.

Step 2: Full Hyperparameter Combination & Evaluation (Part 2)

Proceed to the second section of the Python script/notebook.

Objective: Run the full grid/combination setup using the selected hyperparameters.

Record the evaluation metric results obtained for each distinct hyperparameter combination.

Export or structure these combined results into a clean spreadsheet format (e.g., .csv or .xlsx).

Step 3: Statistical Analysis in R (ANOVA & Scott-Knott Test)

Load the generated spreadsheet/data file into the R script (.R).

Analysis Process:

ANOVA (Analysis of Variance): Performed to test statistical significance across different hyperparameter configurations.

Scott-Knott Test (SK): Applied to group means into statistically distinct clusters without overlapping results.

Extract the final rankings and statistical groupings generated by the R execution.
